# Contributing

Contributions of source research, GIS expertise, accessibility improvements, and thoughtful critique are welcome.

For an archaeological claim, provide the source link and bibliographic information; label whether it is observed, interpreted, or proposed; describe the uncertainty; and explain spatial precision. Do not submit copyrighted figures, scans, datasets, 3D models, or imagery without an applicable redistribution license or explicit permission.

For code contributions, keep the static-site version runnable without a backend; add or extend the catalog validation test if the schema changes. Run `node --test tests/catalog.test.mjs` before proposing changes.

Please propose larger changes in a GitHub issue first, particularly new imagery providers, LiDAR imports, geographic data, or contested historical interpretations. Respect the research contributions of Cambodian scholars and the living communities of Angkor.

## Geospatial contributions

Do not attach georeferenced LiDAR, unpublished archaeological coordinate lists, or digitized source maps without explicit publication permission. Review the layer admission process in [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and the conditions in [docs/data-policy.md](docs/data-policy.md).
