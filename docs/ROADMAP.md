# Roadmap

## v0.1 — Evidence-first map
- [x] Clickable documented monument reference locations
- [x] Evidence tier slider with independently sourced claims
- [x] Citations and explicit uncertainty
- [x] GitHub Pages-compatible static architecture

## v0.2 — Publishable geospatial foundation (current)
- [x] A GeoJSON layer registry with source, license, precision and publication metadata
- [x] Independent confidence threshold alongside evidence tier
- [x] Site-specific shareable permalinks
- [x] Copyable source-linked evidence dossier
- [x] Automated catalog, geometry and licensing checks in GitHub Actions
- [x] Documented geospatial contribution criteria and restricted-data boundaries
- [ ] Archaeologist review of starter claims and coordinate references
- [ ] Independent functional testing in Chromium / Firefox / mobile browsers

## v0.3 — Evidence-rich geography
- [ ] Permissioned, reviewed features (mounds, ponds, canals, embankments, and temple outlines)
- [ ] Feature-level citation and uncertainty UI for line and polygon geometries
- [ ] Era / date range as a distinct filtering dimension (with dating evidence)
- [ ] Data import tooling, original CRS provenance and reproducible derivation notes
- [ ] Production-appropriate map tile provider

## v0.4 — Landscape in 2.5D
- [ ] Properly licensed elevation data or terrain tiles
- [ ] Camera tilt and hillshade, linked to actual feature geometries
- [ ] Compare present landscape to interpreted historical scenarios

## v0.5 — 3D historical hypotheses
- [ ] Source-linked glTF architecture and model confidence
- [ ] Historical scenes with explicit separation of attested and speculative features
- [ ] Optional first-person navigation

**Non-goal:** a visually convincing but unverifiable representation of a lost city.
